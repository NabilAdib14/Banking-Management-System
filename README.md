# Banking Management System


This C# Windows Forms application provides an intuitive platform for managing customer accounts, employees, and loans. Designed with a focus on simplicity and clarity, it helps simulate real-world banking operations for learning and demonstration purposes.

## Features

## User Roles

* **Customer:**
    * View account details and balance
    * Deposit and withdraw money
    * Apply for loans and repay them
* **Employee:**
    * Manage customer information
    * Review and process loan applications
* **Manager/Admin:**
    * Approve or reject loans
    * Manage employees and customers
    * Monitor transactions

## Core Functionalities
* **Secure Login System:**
    * Role-based login for customers, employees, and managers.
* **Account Management:**
    * Create, update, or deactivate accounts.
* **Transaction Handling:**
    * Record deposits, withdrawals, and transfers.
* **Loan Management:**
    * Apply, approve, and track loan repayments.
* **User Interface:**
    * Clean and interactive WinForms GUI.

## Database Information
* Database Name: BankingDB
* SQL Server Version: Microsoft SQL Server 2014

## Installation and Setup
    * Set up the Database: Create a database named BankingManagementSystem.
                                  Run the provided SQL scripts to create tables.
    * Configure the Connection String: Update the database connection path in ApplicationHelper.cs.
    * Run the Application: Open the .sln file in Visual Studio.
                                  Build and run the project.
